# successinBAC2027
Le AFKH Success Pack est un guide complet conçu pour les élèves de 2Bac (Sciences Physiques et SVT). Il regroupe des résumés de cours, des séries d'exercices, les cadres référentiels, des examens nationaux corrigés (Maths, PC, SVT, Anglais, Philosophie) et un plan de révision pour réussir avec excellence.
